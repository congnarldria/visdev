程式一行一個敘述。算子名稱不分大小寫，變數名稱則要完全一致。tuple 索引從 1 開始。

          
* 這是註解
read_image (Image, 'samples/parts.png')
MinGray := 80
threshold (Image, Region, MinGray, 255)
Area := [10, 20, 30]
First := Area[1]
Length := |Area|
Label := 'n=' + Length
for Index := 1 to Length by 1
  if (Area[Index] > 15)
    stop ()
  endif
endfor

          
行尾的 \ 表示這一行還沒結束。路徑請寫 C:/data/a.png，不要用結尾的反斜線。

          
if 的條件若是 tuple，必須每一個元素都成立才會進去。= 是比較，:= 才是指定。# 和 <> 都是不等於。
