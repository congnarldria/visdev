程式一行一個敘述。算子名稱不分大小寫，變數名稱則要完全一致。運算式 T[1] 的索引從 1 開始。tuple_select 這類算子的索引從 0 開始，和 HALCON 一樣。

          
ho_ 是 HObject。幾個區域，或幾條輪廓，用 := 放進同一個 tuple，會收成一個物件集合再傳進程序和算子。圖形視窗每一塊用不同顏色。ho_Objects[1] 是第一個，從 1 開始。hv_ 是 HTuple，索引從 0 開始。

          
* 這是註解
Vizion.read_image (Image, 'samples/parts.png')
MinGray := 80
Vizion.threshold (Image, Region, MinGray, 255)
Area := [10, 20, 30]
First := Area[1]
Length := |Area|
Label := 'n=' + Length
for Index := 1 to Length by 1
  if (Area[Index] > 15)
    Vizion.stop ()
  endif
endfor

          
行尾的 \ 表示這一行還沒結束。路徑請寫 C:/data/a.png，不要用結尾的反斜線。

          
if 的條件若是 tuple，必須每一個元素都成立才會進去。= 是比較，:= 才是指定。# 和 <> 都是不等於。

使用說明

      
這是 VisDev 1.1 beta，不是正式版。

      
執行

      
F5 執行，F6 單步，F7 步進程序。程式跑到一半失敗時，已經算出的圖和變數留著，狀態列會寫出第幾行，相機和檔案會關掉。執行中若已經有直徑、寬度、合格或不合格，狀態列會直接寫出來。跑完或停止後也會留著這些數字。變數很多時，單步只改有變動的那一列。打字時語法著色、行號和該行時間只改有變動的列。輸出往上翻時，新的一行不會把畫面拉回底部。錯誤清單只改有變動的列。大圖在執行中會先縮小顯示，標題會寫預覽，跑完或停止後換成完整圖。

      
範本

      
檔案、範本打開就能跑。跑完後，狀態列和圖形視窗會寫出下面這些數字。

      
    
        
  • 零件檢測：samples/parts.png，8 個零件。狀態列寫個數。
    • 
        
  • 瑕疵：samples/hard_contrast.png。暗塊 1 個、面積 3550；亮點 1 個、面積 144。預設灰階是暗塊 0 到 40、亮點 210 到 255。圖形視窗可以改這兩個範圍，再按執行。
    • 
        
  • 色彩：samples/color_part.png。綠塊面積 1200、色調 60。紅塊色調是 0，灰底飽和度是 0，都不計。預設色調 50 到 70、面積 1100 到 1300。圖形視窗可以改這兩個範圍。超出時判定不合格，區域是紅色。
    • 
        
  • 邊緣量測：samples/gauge.png。狀態列寫間距。
    • 
        
  • 卡尺：同一張圖。直徑約 83.93，寬 140，高 90。預設公差是直徑 80 到 90、寬 130 到 150、高 80 到 100。圖形視窗可以改上下限，再按執行。卡尺、條紋和瑕疵改過的範圍會記在這台電腦，再打開同一支範本會填回去。按「預設」回到程式裡的數字。存進專案的程式以檔案裡的數字為準。超出的線是紅色。
    • 
        
  • 條紋寬度：samples/stripes.png。最寬的亮條是 22，預設公差 20 到 24。圖形視窗可以改上下限，再按執行。超出時十字是紅色。
    • 
        
  • 產線：samples/line_batch 有 5 張，白塊面積 200 以上算合格。合格 3、不合格 2。不合格的圖在 workspace/line_ng，明細在 workspace/line_result.csv。這支用檔案資料夾，不開相機。再跑一次會先清掉上一輪的不合格圖。狀態列的不合格圖是最近一張，ng_02.png。按「看不合格圖」把它開回圖形視窗，再按一次回到程式畫面。按「看明細」可看 CSV。明細裡可以只看不合格，點不合格那一列會打開那張圖。不必開資料夾。
    • 
        
  • 產線相機：本機相機編號 0。Windows 先問 DirectShow，打不開再試 OpenCV。沒有相機時，請改跑上面的產線，用 samples/line_batch。規則和產線相同，明細每一列是這張的 OK 或 NG。執行中狀態列會寫出合格和不合格。按停止就停，已經計的張數留著，不合格圖是最近一張的檔名。出錯也會關掉相機和 CSV。明細在 workspace/line_camera.csv。
    • 
        
  • 產線輸出：同一套 5 張。每一張多送一行 VISDEV,OK 或 NG,合格張數,不合格張數,檔名。這支用 TCP loopback，變數 Wire 是讀回來的 5 行。合格仍是 3、不合格仍是 2。要送到外面，把 loopback 改成主機和埠號，或改成 open_serial 的 COM 名稱。Windows 開 COM 的方式沒有改。
    • 
        
  • 形狀定位：場景裡找到 4 個。狀態列寫個數和最低分。
    • 
        
  • 相對姿態：Pose1 的第一個數約 0.04 公尺。狀態列寫基線。
    • 
        
  • 條碼：Text 是 4006381333931，QrText 是 VISDEV-3。
    • 
      

      
點量規或直線量規時，可以按「線」在圖上拖。起點到終點的方向會保留。圖上已有影像時，確認前會畫出沿這條線找到的邊緣和首尾間距。

      
把結果送到外面

      
產線輸出每一張寫一行，TCP 和序列埠相同：VISDEV,OK 或 NG,合格張數,不合格張數,檔名，結尾換行。合格、不合格會寫成 OK、NG。檔名用英文。範本用 loopback，Wire 讀回那 5 行，所以合格仍是 3、不合格仍是 2。送到外面時，把 open_socket_connect 的 loopback 改成主機和埠號，或改成 open_serial ('COM3', Link)，並拿掉 receive_data。Windows 開 COM 仍用原來的 API，不在這一行裡重開。

      
標定

      
棋盤寫 '5,7,10'，也可以用 .cpd 或 .descr。多台相機時，每一台的第 k 組要是同時看到的同一塊板。camera/pose 是相對第 0 台的姿態，第 0 台是 0。標完的圖可以點某一張看原圖，再點一下回到全部。

      
存檔與 Windows

      
存檔在 workspace/。檔案、專案可以把多支程式放在同一個案子裡。存進去時，程式讀的 workspace/ 圖會拷進專案資料夾，路徑改成檔名。samples/ 的圖仍共用。可以改名，也可以打開資料夾看圖在不在。從檔案總管貼上的反斜線路徑也能讀。Windows 上用 run.bat 開啟，用 build_windows.bat 打包。打包需要 Python 3.9 或更新版本、visdev_match.pyd 和 PyInstaller。形狀匹配在 Windows 用這個 .pyd。

      

    

  

  

    

      
VisDev 1.1 beta

      
視覺開發環境。程式寫法接近 HDevelop，影像計算用 OpenCV。

      
上方選單：檔案可以新增、開啟、儲存、載入影像，也可以把讀圖、定義域、二值化、連通、篩選、矩形和圓形形態學、個數和重心匯出成 C#。編輯可以復原、剪貼。檢視可以開關窗格和縮放。執行是 F5、F6、F7。運算子依分類列出，點了會開參數窗再插入程式。工具會另開二值化、次像素、特徵和 OCR。
