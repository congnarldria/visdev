程式一行一個敘述。算子名稱不分大小寫，變數名稱則要完全一致。運算式 T[1] 的索引從 1 開始。tuple_select 這類算子的索引從 0 開始，和 HALCON 一樣。

          
* 這是註解
read_image (Image, 'samples/parts.png')
MinGray := 80
threshold (Image, Region, MinGray, 255)
Area := [10, 20, 30]
First := Area[1]
Length := |Area|
Label := 'n=' + Length
for Index := 1 to Length by 1
  if (Area[Index] > 15)
    stop ()
  endif
endfor

          
行尾的 \ 表示這一行還沒結束。路徑請寫 C:/data/a.png，不要用結尾的反斜線。

          
if 的條件若是 tuple，必須每一個元素都成立才會進去。= 是比較，:= 才是指定。# 和 <> 都是不等於。

        

      

      

        

      

    

  


  

    

      
VisDev

      
視覺開發環境。程式寫法接近 HDevelop，影像計算用 OpenCV。

      
上方選單：檔案可以新增、開啟、儲存和載入影像。編輯可以復原、剪貼。檢視可以開關窗格和縮放。執行是 F5、F6、F7。運算子依分類列出，點了會開參數窗再插入程式。工具會另開二值化、次像素、特徵和 OCR。
